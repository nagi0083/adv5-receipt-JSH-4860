이제 화면을 만들자. 02 화면설계(시안 모양 그대로) · 03 기능정의서 · 04 데이터정의서대로.
먼저 public 폴더를 만들고 public\config.js 를 채워 줘. 커넥터로 adv5-receipt의 주소와 공개용 키(sb_publishable_ 로 시작하는 것)를 가져와서. 비밀 키는 가져오지도 적지도 마.

만들 파일은 네 가지야.
- public\index.html — 화면 전부. 시안 모양 그대로, 가짜 데이터와 "상태 보기" 링크는 빼고 03의 F 기능을 전부 넣는다. supabase-js는 CDN에서 불러오되 버전을 고정한다. 설치 없음. 화면 맨 아래에 작은 글씨로 v1.0 을 표시한다.
- public\config.js — 주소 · 공개용 키 두 값만. index.html이 열릴 때 이 파일을 읽는다.
- run.bat — 더블클릭하면 이 폴더로 이동해 Python 기본 기능(http.server)으로 public 폴더만 http://127.0.0.1:8001 로 열고, 서버가 준비되면 크롬이 켜진다. 내 PC(127.0.0.1)에서만. 오류가 나면 창이 바로 닫히지 않게.
- README.md — 무엇을 하는지, 내 PC에서 여는 방법, 배포 주소로 여는 방법, config.js에 무엇이 들어 있나, 사진 20장을 저장소에 올리는 방법(03의 M 번호로), 인터넷에 공개되는 것은 public 폴더뿐이라는 것

[지켜야 할 것]
- 주소와 공개용 키는 config.js에서 읽는다. index.html에 직접 적지 않는다. input\설정.txt 는 만들지도 읽지도 않는다.
- public 폴더에는 index.html · config.js 두 파일만 둔다. 문서 · SQL · input · output은 넣지 않는다.
- 웹 등록 사진은 저장소 receipts에 올리고, 파일 이름은 화면이 web_날짜_시각_임의4자리 형식(영문 · 숫자)으로 새로 짓는다. 표에는 그 파일 이름만.
- 사진은 볼 때만 10분짜리 임시 주소로 연다.
- 일시는 영수증에 적힌 그대로 보여 준다(시간대를 바꾸지 않는다). 등록 화면에서는 날짜(달력)와 시각(24시간, 예 12:20)을 따로 받는다.
- 고치기 · 지우기 버튼은 만들지 않는다. 웹 등록에는 품목과 카드 끝 4자리를 넣지 않는다.
- 집계: 월은 일시의 연-월, 처음엔 가장 최근 월. 택시는 목적별에서 "목적 없음". 식사 1인당 = 식사 합계 ÷ 식사 인원 합계, 원 단위 반올림.

코드를 쓰기 전에 계획을 먼저 보여 주고, 내가 확인하면 만들어 줘.
만든 뒤 run.bat을 실행하지는 마. 브라우저 확인은 내가 할게. 대신 03의 F-번호마다 index.html 어디에 들어갔는지 한 줄씩 알려 주고, 표 · 칸 · 저장소 이름이 04와 같은지, public 폴더 안에 파일이 두 개뿐인지, config.js에 sb_secret_ 이 없는지 스스로 점검해서 결과만 알려 줘.
