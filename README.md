# adv5-receipt — 경비 정산 웹앱 (v1.0)

영업팀 직원 8명이 법인카드 영수증을 한 곳(Supabase)에 모으는 웹앱입니다.

- 직원은 폰이나 PC 브라우저에서 영수증 사진과 내용을 **등록**하고, 모두의 **목록**과 **집계**를 봅니다.
- 집계: 월별 건수 · 합계, 구분별(식사 · 카페 · 택시) · 목적별(일반 · 회식 · 접대 · 목적 없음) · 직원별 합계, 식사 1인당 금액(식사 합계 ÷ 식사 인원 합계, 원 단위 반올림).
- 로그인이 없으므로 **연습용 가상 데이터만** 넣습니다.
- 자세한 내용은 `개발문서\01_요구사항정의서.md` ~ `05_테스트목록.md`를 봅니다.

## 내 PC에서 열기 (확인용)

1. 이 폴더의 `run.bat`을 더블클릭합니다. (설치할 것은 없습니다. 이 PC에 Python 3가 있어야 합니다.)
2. 검은 창이 뜨고, 준비되면 크롬이 `http://127.0.0.1:8001` 을 엽니다.
3. 확인이 끝나면 검은 창을 닫습니다.

- `public` 폴더만 열리고, 내 PC(127.0.0.1)에서만 열립니다. 같은 사무실의 다른 PC에서는 열리지 않습니다.
- 오류가 나면 창이 닫히지 않고 이유를 보여 줍니다(예: Python 없음, 8001번 포트 사용 중).

## 배포 주소로 열기 (직원용)

- Vercel이 준 주소 `https://….vercel.app` 를 폰 · PC 브라우저에서 엽니다. 내 PC가 꺼져 있어도 열립니다.
- Vercel 설정(M-07): Framework Preset **Other** · Build Command 비움 · Output Directory **`public`** · 환경 변수 없음.
- GitHub 저장소 `adv5-receipt`(비공개)의 `main`에 올리면 자동으로 다시 배포됩니다. 화면 맨 아래 버전(v1.0)으로 어느 버전인지 확인합니다.

## config.js 에 들어 있는 것

`public\config.js` 에는 두 값만 있습니다. Claude가 Supabase 커넥터로 가져와 채웠습니다.

| 항목 | 내용 |
|---|---|
| `SUPABASE_URL` | Supabase 프로젝트 주소 (`adv5-receipt--240104`) |
| `SUPABASE_KEY` | 공개용 키 (`sb_publishable_…`). 인터넷에 공개되어도 됩니다 — 할 수 있는 일은 권한 규칙(RLS)이 정합니다 |

- 비밀 키(`sb_secret_…`)와 DB 비밀번호는 어디에도 적지 않습니다. 다른 설정 파일이나 환경 변수는 쓰지 않습니다.
- 화면(공개용 키)이 할 수 있는 일: 직원 · 영수증 · 품목 읽기, 영수증 넣기(등록 방식 "웹"만), 사진 올리기(`web_…` 이름만)와 보기(10분 임시 주소). 고치기 · 지우기는 할 수 없습니다.

## 확인용 사진 20장을 저장소에 올리는 방법

| 순서 | 할 일 | 기능 |
|---|---|---|
| 1 | Supabase 대시보드 → 프로젝트 `adv5-receipt--240104` → **Storage** → **receipts** 를 엽니다. | M-01 |
| 2 | **Upload** 로 `input\영수증사진\receipt_01.jpg` ~ `receipt_20.jpg` 를 **이름 그대로** 올립니다. `웹등록용\receipt_21.jpg` 는 올리지 않습니다(화면에서 등록). | M-01 |
| 3 | receipts 가 비공개(Public 표시 없음)이고 사진이 20장인지 봅니다. Table Editor 에서 표 3개와 줄 수도 봅니다. | M-03 |

영수증 내용(표에 넣는 일)은 Claude가 사진을 읽어 `output\읽은결과.xlsx` 를 만들고, 정산 담당이 확인한 뒤 커넥터로 넣습니다(A-04, A-05).

## 인터넷에 공개되는 것

**`public` 폴더 하나뿐입니다.** 그 안에는 `index.html`(화면)과 `config.js`(설정) 두 파일만 둡니다.

| 폴더 · 파일 | 어디까지 |
|---|---|
| `public\` | 인터넷 공개(배포 주소) |
| `개발문서\` · `output\sql\` · `시안\` · `프롬프트\` · `run.bat` · `README.md` · `CLAUDE.md` | GitHub 비공개 저장소까지 |
| `input\` · `output\읽은결과.xlsx` | 내 PC만 (.gitignore) |

배포 주소 뒤에 `/README.md`, `/CLAUDE.md` 를 붙여도 열리지 않아야 합니다(T-19).
