## 1. 화면 목록

| 번호 | 화면 | 하는 일 | 누가 | 근거 |
|---|---|---|---|---|
| S-01 | 등록 | 영수증 사진과 내용을 넣는다 | 직원 | (R-02, R-03) |
| S-02 | 목록 | 영수증을 최근 순으로 보고, 월 · 제출자 · 구분으로 골라 본다 | 직원 · 정산 담당 | (R-04) |
| S-03 | 집계 | 한 달의 건수 · 합계, 구분별 · 목적별 · 직원별 합계, 식사 1인당 금액을 본다 | 직원 · 정산 담당 | (R-06) |
| S-04 | 상세 | 영수증 한 장의 사진 · 내용 · 품목을 본다 (목록에서 줄을 누르면 열림) | 직원 · 정산 담당 | (R-05) |

- 화면은 한 페이지이고, 맨 위의 탭 세 개(등록 · 목록 · 집계)로 바꿔 본다. 상세는 목록 위에 겹쳐 열린다. (R-01)
- **화면에 없는 일** — 아래 일은 화면이 아니라 정산 담당이 Claude와 대화로 한다.
  - 확인용 데이터 넣기: 사진 20장 읽기 → 읽은결과.xlsx 확인 → 넣기 (R-12, R-13)
  - 묻기 · 고치기: "10월 접대비 합계는?", "이 영수증 인원을 4명으로" (R-14)
  - 고치기 · 지우기 버튼은 화면에 없다. (R-01)
- **여는 곳**
  - 직원: 배포 주소(`https://….vercel.app`)를 폰이나 PC에서 연다. (R-20, R-21)
  - 정산 담당: 만들면서 확인할 때는 내 PC에서 `run.bat`을 더블클릭해 연다(http://127.0.0.1:8001). 배포 뒤에는 직원과 같은 배포 주소로도 확인한다. (R-15, R-21)

## 2. 화면 그림

모든 화면 공통: 맨 위에 제목과 탭 세 개, 맨 아래에 작은 글씨로 버전 `v1.1`(R-26). 지금 보고 있는 탭은 [ ]로 표시. 그림 속 숫자는 배치를 보여 주기 위한 예시다. (R-01, R-08)

### S-01 등록 (R-02, R-03)

```
┌──────────────────────────────────────┐
│ 경비 정산                            │
│ [등록]   목록    집계                │
├──────────────────────────────────────┤
│ (상태 문장 자리)                     │
│                                      │
│ 제출자    [ 직원 고르기          ▼ ] │
│ 사진      [ 파일 선택 ] receipt.jpg  │
│ 구분      [ 식사 / 카페 / 택시   ▼ ] │
│ 날짜      [ 2026-11-06        📅 ]   │
│ 시각      [ 12:20 ]  (24시간)        │
│ 가게 이름 [                      ]   │
│ 합계(원)  [                      ]   │
│ 목적      [ 일반 / 회식 / 접대   ▼ ] │ ← 택시면 숨김
│ 인원      [      ]                   │ ← 택시면 숨김
│ 접대 상대 [                      ]   │ ← 접대일 때만 보임
│ 메모      [                      ]   │
│                                      │
│             [   등록   ]             │
├──────────────────────────────────────┤
│                                v1.1  │
└──────────────────────────────────────┘
```

- 제출자는 "박서연 (영업1팀 과장)"처럼 이름 · 부서 · 직급으로 보여 준다(이름이 비슷한 직원을 헷갈리지 않게).
- 품목과 카드 끝 4자리 칸은 없다. (R-02)

### S-02 목록 (R-04, R-25)

```
┌──────────────────────────────────────────────────────┐
│ 경비 정산                                            │
│  등록   [목록]   집계                                │
├──────────────────────────────────────────────────────┤
│ 21건 · 1,729,200원                ← 요약 줄 (R-25)   │
│ 월 [2026-10 ▼]   제출자 [전체 ▼]   구분 [전체 ▼]     │
│ (상태 문장 자리)                                     │
│ ──────────────────────────────────────────────────── │
│ 일시             제출자  구분  가게        합계  등록│
│ ──────────────────────────────────────────────────── │
│ 2026-10-23 19:10 이서연  식사  화로정    288,000  AI │
│ 2026-10-23 12:20 김준호  식사  봄날 국밥  22,000  웹 │
│ 2026-10-22 16:05 오세진  카페  커피 한모금 8,000  AI │
│ …                                                    │
├──────────────────────────────────────────────────────┤
│                                                v1.1  │
└──────────────────────────────────────────────────────┘
```

- 맨 위 요약 줄은 지금 고른 조건(월 · 제출자 · 구분)에 맞는 건수와 합계를 "n건 · n원"으로 보여 주고, 조건을 바꾸면 함께 바뀐다. 맞는 영수증이 없으면 "0건 · 0원". (R-25)
- 줄을 누르면 S-04 상세가 열린다.

### S-03 집계 (R-06)

```
┌──────────────────────────────────────┐
│ 경비 정산                            │
│  등록    목록   [집계]               │
├──────────────────────────────────────┤
│ 월 [2026-10 ▼]                       │
│ (상태 문장 자리)                     │
│                                      │
│ 건수  21건      합계  1,729,200원    │
│ 식사 1인당  00,000원                 │
│  (식사 합계 ÷ 식사 인원 합계)        │
│                                      │
│ 구분별 합계                          │
│   식사 / 카페 / 택시      건수 · 금액│
│                                      │
│ 목적별 합계                          │
│   일반 / 회식 / 접대 / 목적 없음     │
│                           건수 · 금액│
│                                      │
│ 직원별 합계 (금액 많은 순)           │
│   이름 (부서)             건수 · 금액│
├──────────────────────────────────────┤
│                                v1.1  │
└──────────────────────────────────────┘
```

### S-04 상세 (R-05)

```
┌──────────────────────────────────────┐
│ 영수증 상세                  [닫기]  │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │        (영수증 사진)             │ │
│ └──────────────────────────────────┘ │
│ 구분 식사      일시 2026-10-01 12:12 │
│ 가게 한결식당  합계 28,000원         │
│ 제출자 박서연 (영업1팀)              │
│ 목적 일반  인원 2  접대 상대 -       │
│ 카드 끝 4821   등록 방식 AI          │
│ 메모 외근 중 점심 — 이도현 대리와    │
│ ──────────────────────────────────── │
│ 품목          수량   단가     금액   │
│ 김치찌개        2   9,500   19,000   │
│ 계란말이        1   9,000    9,000   │
│ ──────────────────────────────────── │
│ 품목 합 28,000 = 합계 28,000  일치   │
├──────────────────────────────────────┤
│                                v1.1  │
└──────────────────────────────────────┘
```

- 웹 등록분은 품목 표 자리에 "품목 없음"이라고 쓴다.
- 품목 합과 합계가 다르면 "불일치 (차이 n원)"이라고 쓴다.

## 3. 사용 흐름

### 직원 (R-02 ~ R-05)
1. 폰이나 PC에서 배포 주소를 연다. 등록 탭이 먼저 보인다.
2. 제출자에서 자기 이름을 고른다.
3. 영수증 사진을 고르고, 구분 · 날짜 · 시각 · 가게 이름 · 합계를 적는다.
4. 식사 · 카페면 목적과 인원을 적는다. 접대면 접대 상대도 적는다. 택시면 이 칸들이 사라진다.
5. 필요하면 메모를 적고 [등록]을 누른다.
6. "등록했습니다."를 확인한다. 칸이 빈칸으로 돌아간다.
7. 목록 탭에서 제출자를 자기 이름으로 고르고, 방금 등록한 줄(등록 방식 "웹")을 찾는다.
8. 그 줄을 눌러 상세에서 사진과 내용이 맞는지 본다. 틀렸으면 정산 담당에게 알린다(화면에서 고치지 않는다).

### 정산 담당 (R-04 ~ R-06, R-14)
1. 내 PC에서 `run.bat`을 더블클릭하거나 배포 주소를 연다.
2. 목록 탭에서 월을 고르고 전체 영수증을 본다. 필요하면 제출자 · 구분으로 좁힌다.
3. 확인할 줄을 눌러 상세에서 사진 · 내용 · "품목 합 = 합계"를 본다.
4. 상세를 닫고 집계 탭으로 간다.
5. 월을 고르고 건수 · 합계, 구분별 · 목적별 · 직원별 합계, 식사 1인당 금액을 본다.
6. 숫자가 궁금하거나 고칠 것이 있으면 Claude에게 말로 묻거나 요청한다. 고친 뒤 화면을 새로 열어 바뀐 값을 확인한다.

## 4. 화면 상태 네 가지 (R-07)

| 상태 | 언제 | 보이는 것 | 잠기는 것 |
|---|---|---|---|
| **불러오는 중** | 화면을 처음 열 때, 월 · 조건을 바꿀 때, 상세를 열 때, 등록을 누른 뒤 저장하는 동안 | "불러오는 중…" (등록 중에는 "등록 중…") | 등록 버튼, 월 · 제출자 · 구분 고르기. 등록 중에는 모든 입력 칸도 잠근다(두 번 저장 막기) |
| **정상** | 데이터를 다 받았을 때 | 목록 줄 · 집계 숫자 · 상세 내용. 등록 성공 시 "등록했습니다." | 없음 |
| **비어 있음** | 고른 조건에 영수증이 없을 때 | 표 자리에 "이 조건에 맞는 영수증이 없습니다." / 집계는 "이 달에 등록된 영수증이 없습니다." / 상세 웹 등록분은 품목 자리에 "품목 없음" | 없음(다른 조건을 고를 수 있다) |
| **오류** | 인터넷이 끊겼거나, 서버가 거절했거나, 칸이 잘못 들어갔을 때 | 빨간 글씨로 이유를 문장으로. 예: "인터넷 연결을 확인해 주세요." / "시각은 12:20처럼 24시간 형식으로 적어 주세요." / "사진을 열지 못했습니다. 잠시 뒤 다시 열어 주세요." | 없음. 입력한 내용은 그대로 남아 고쳐서 다시 등록할 수 있다. 사진이 올라간 뒤 저장만 실패했으면 그 사실도 알린다 |

## 5. 폰에서 보이는 모습 (R-08)

| 부분 | 넓은 화면(PC) | 좁은 화면(폰) |
|---|---|---|
| 탭 | 제목 아래 한 줄 | 그대로 한 줄, 손가락으로 누르기 쉬운 크기 |
| 등록 칸 | 이름표와 칸이 옆으로 나란히 | **이름표 아래에 칸이 오고, 한 줄에 칸 하나씩** 위에서 아래로. 칸 폭은 화면 폭 가득 |
| 등록 버튼 | 가운데 | 화면 폭 가득 |
| 사진 고르기 | 파일 선택 | 폰 사진첩이나 카메라에서 고른다 |
| 목록 조건 고르기 | 한 줄에 셋 | 한 줄에 하나씩 아래로 |
| 목록 표 | 한 화면에 모든 칸 | 표만 옆으로 밀어서 본다(화면 전체는 옆으로 밀리지 않음). 일시 · 가게 · 합계가 먼저 보이게 |
| 집계 | 표 여러 개 | 표를 위에서 아래로 하나씩 |
| 상세 | 화면 가운데 창 | 화면 전체를 덮는 창, 사진은 폭에 맞춰 줄임 |
| 버전 표시 | 맨 아래 오른쪽 작은 글씨 | 같음 |
